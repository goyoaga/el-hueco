## Cómo jugar

El viento empuja el globo automáticamente hacia la derecha.

**Mantén pulsado 🔥 QUEMADOR** para ganar altura y suéltalo para dejar de ascender. Puedes usarlo tantas veces como necesites.

Tu única misión: **pasar entre las dos nubes sin tocarlas**.

☁️ Si pasas limpio: confeti.  
⚡ Si rozas una nube: un rayo apaga tu vuelo.

Después siempre queda una opción: **UNA MÁS**.
